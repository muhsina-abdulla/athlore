# Roadmap

Athlore will be built in stages, starting with the core training journal and gradually adding progress tracking, analytics, and training intelligence.

The roadmap describes the planned direction of the project rather than fixed deadlines. The order may change as the product develops and I learn from using it.

## Phase 1 — Foundation

- [x] Initialize React Native + Expo + TypeScript project
- [x] Set up Git and GitHub repository
- [x] Establish initial app structure
- [x] Define initial product vision and requirements
- [x] Create initial project documentation
- [x] Create initial visual direction

## Phase 2 — Core Training Journal

Build the foundation for recording and reviewing MMA training.

- [ ] Google authentication
- [ ] Training session creation
- [ ] Session editing
- [ ] Multiple sessions per training day
- [ ] Session types and categories
- [ ] Exercise-level tracking
- [ ] Local draft saving
- [ ] Draft recovery
- [ ] Reliable session submission and synchronization
- [ ] Training history
- [ ] Session details and editing

## Phase 3 — Progress Tracking

Turn the training history into a clearer view of progress.

- [ ] Goals
- [ ] Goal-specific milestone paths
- [ ] Automatic measurable milestones
- [ ] Manual skill milestones
- [ ] Milestone progress views
- [ ] Basic progress statistics

## Phase 4 — Analytics

Start exploring what the accumulated training data reveals.

- [ ] Training frequency and consistency
- [ ] Training duration trends
- [ ] Category and session-type breakdowns
- [ ] Self-rating trends
- [ ] Exercise history
- [ ] Training-day vs session-level analytics
- [ ] Milestone-related analytics
- [ ] Initial pattern discovery

## Phase 5 — Training Intelligence

Use the training history to answer questions and surface useful insights.

- [ ] Historical training data retrieval
- [ ] Ask questions about training history
- [ ] Retrieve previously learned techniques and skills
- [ ] Retrieve relevant coach feedback
- [ ] Identify recurring areas for improvement
- [ ] Weekly AI-generated insights
- [ ] On-demand insights
- [ ] Clear distinction between recorded information and AI-generated analysis

## Phase 6 — Training Planning

Connect historical training data with future training.

- [ ] Identify areas that may need revisiting
- [ ] Surface skills that have not been trained recently
- [ ] Connect goals with relevant training history
- [ ] Use previous reflections and coach feedback when planning
- [ ] Explore AI-assisted session planning

## Future Scope

These are possibilities to consider as Athlore evolves:

- Configurable logging metrics
- Support for other athletes and training styles
- Additional platform support, including iOS
- More advanced analytics
- More advanced training intelligence
- Additional integrations

The roadmap will evolve as I build, use, and learn from Athlore.
